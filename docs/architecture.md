## Память (хранение данных)

Всё хранится локально в SQLite: приложение работает без интернета, аккаунт не нужен.

| Таблица | Назначение |
|---|---|
| `lists` | списки (название, тип магазина, даты) |
| `items` | позиции (название, количество, галочка, порядок, «добавлено по подсказке») |
| `history` | что и как часто пользователь покупает в каждом типе магазина — для автодополнения и «частых» |
| `pairs` | что покупается вместе — обучаемая часть ассистента |

Миграции схемы — в `AppDatabase.onUpgrade` (номер версии в `_version`). Настройки и кэш VIP хранятся в
`shared_preferences`. Синхронизации между устройствами в MVP нет; задел для неё — repository-слой,
за который можно поставить Firebase или Supabase.

## ИИ-ассистент: почему гибрид

Большая языковая модель на каждый товар — это дорого, медленно и требует сети. Для задачи
«к гвоздям нужен молоток» достаточно знаний о типичных сочетаниях, поэтому ассистент работает в три уровня:

1. **Правила из встроенной базы** (`catalog.json`: около 320 товаров по отделам и 110 правил связей).
   Работают мгновенно, офлайн и бесплатно. Базу легко расширять без программирования.
2. **Память пользователя.** Каждое добавление обновляет `history` и `pairs`. Если человек два раза и больше
   покупал «пиво» вместе с «чипсами», приложение начнёт это предлагать, даже если правил на этот счёт нет.
   Частые покупки, которых давно не было, тоже всплывают с пометкой «часто покупаете».
3. **Облачная LLM (только VIP, по желанию).** Нужна для необычных сочетаний. Запрос идёт на ваш сервер
   (`server/`, Cloudflare Worker), который обращается к модели; ключ в приложении не хранится.
   Отправляются только тип магазина и названия товаров.

**Ненавязчивость.** Подсказки выводятся компактной лентой под полем ввода: касание добавляет товар,
долгое нажатие убирает подсказку для этого списка, крестик скрывает ленту. Окно с вопросом появляется
ровно один раз — при переходе в режим «в магазин», и только если есть что предложить.
Подсказки можно выключить в настройках.

## Разбор ввода

`InputParser` делит фразу по запятым и союзам («и», «ещё», «плюс»), затем жадно сопоставляет слова
с каталогом через стеммер. Поэтому голосовая фраза без знаков препинания «два литра молока хлеб» даёт
две позиции: «Молоко — 2 литра» и «Хлеб». Незнакомый товар сохраняется как есть. Числительные словами
превращаются в цифры, единицы измерения уходят в количество. Тесты — `test/input_parser_test.dart`.

## Реклама

| Сборка | Сеть | Где показывается |
|---|---|---|
| `STORE=rustore` | Яндекс Реклама | баннер на главном экране и в редактировании списка |
| `STORE=gplay` | AdMob (+ форма согласия UMP для ЕС) | то же |

Межстраничная реклама показывается только после завершения покупок, не чаще раза в 4 минуты
и не в первые два запуска. В режиме «в магазине» рекламы нет. VIP отключает рекламу полностью.
