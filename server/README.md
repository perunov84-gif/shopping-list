# Облачный ИИ-ассистент (опционально, для VIP)

Приложение полностью работает без этого сервера: базовые подсказки («гвозди → молоток»)
и обучение на привычках пользователя выполняются на телефоне. Сервер добавляет «умный»
уровень для необычных сочетаний и включается только у VIP-пользователей.

## Развёртывание (≈10 минут, бесплатно на Cloudflare)

1. Зарегистрируйтесь на https://dash.cloudflare.com и установите Node.js.
2. В папке `server/`:
   ```bash
   npx wrangler login
   npx wrangler secret put ANTHROPIC_API_KEY   # ключ с https://console.anthropic.com
   npx wrangler secret put APP_TOKEN           # любая длинная случайная строка
   npx wrangler deploy
   ```
3. Wrangler выведет адрес вида `https://shopping-list-ai.<имя>.workers.dev`.
4. Добавьте в GitHub → Settings → Secrets and variables → Actions:
   * `AI_ENDPOINT` — адрес из шага 3
   * `AI_APP_TOKEN` — та же строка, что и `APP_TOKEN`

   CI передаст их в сборку через `--dart-define`.

## Стоимость

Модель `claude-haiku-5-5`, ~300 токенов на запрос, плюс кэш одинаковых запросов на сутки.
Ориентировочно доли цента за запрос; запросы шлют только VIP-пользователи и только после
изменения списка (с задержкой), так что расход предсказуем. Любую другую LLM можно подставить,
поменяв один `fetch` в `src/index.js`.
