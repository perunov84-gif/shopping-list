# 🛒 Список покупок

Мобильное приложение для Android и iOS (Flutter): списки покупок по магазинам в пару касаний или голосом,
ассистент «не забыть купить» и режим «в магазине» с галочками.

**Скачать тестовую сборку:** [Releases](https://github.com/perunov84-gif/shopping-list/releases/latest)
(`shopping-list-rustore.apk` — Яндекс Реклама, `shopping-list-gplay.apk` — AdMob).

## Возможности

| | |
|---|---|
| **Списки по магазинам** | Продукты, строительный, хозтовары, аптека, зоотовары, детские, электроника, сад и дача, другое. Новый список — 2 касания. |
| **Быстрый ввод** | Несколько товаров за раз через запятую («молоко 2 л, хлеб, яйца»), автодополнение, «частые» товары одним касанием. |
| **Голос** | В списке: «два литра молока, хлеб и десяток яиц». На главном экране: «в строительный гвозди и молоток, в аптеку пластырь» — товары сами разложатся по спискам. |
| **Ассистент** | Подсказки «возможно, понадобится» (гвозди → молоток, краска → валик) появляются ненавязчивой лентой; перед походом в магазин — однократная проверка «Ничего не забыли?». Учится на привычках пользователя. |
| **Режим «в магазине»** | Крупные строки, группировка по отделам, купленное уходит вниз, прогресс, без рекламы. |
| **Прочее** | Повтор списка, «поделиться» текстом, перестановка, удаление свайпом с отменой, тёмная тема, работа офлайн. |
| **Монетизация** | Бесплатно с рекламой; VIP — разовая покупка: без рекламы + облачный ИИ. |

## Сборка

Каждый push в `main` собирает обе APK в GitHub Actions и публикует их в Releases.
Локально (нужны Flutter 3.38+ и Android SDK):

```bash
flutter pub get
flutter test
flutter build apk --release --dart-define=STORE=rustore   # или STORE=gplay
flutter build appbundle --release --dart-define=STORE=gplay  # для Google Play
```

Параметры сборки (`--dart-define`): `STORE`, `ADMOB_BANNER_ID`, `ADMOB_INTERSTITIAL_ID`,
`YANDEX_BANNER_ID`, `YANDEX_INTERSTITIAL_ID`, `VIP_PRODUCT_ID`, `RUSTORE_APP_ID`, `AI_ENDPOINT`, `AI_APP_TOKEN`,
`TEST_BUILD`. Без них используются тестовые ID рекламы — безопасно для разработки.
